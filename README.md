# GCS Semana 2 — Baseline v1.0 (Proyecto: EmilyAyuda)

## Objetivo del proyecto
EmilyAyuda es una plataforma donde clientes suben tareas académicas con su
descripción y fecha límite, y Emily las resuelve a cambio de un pago. Este
repositorio aplica los fundamentos de Gestión de la Configuración del
Software: estructura de repositorio, commits trazables y una línea base
(Baseline v1.0).

## Cómo ejecutar
```bash
node src/main.js
```

## Cómo se creó la línea base (Baseline v1.0)
1. Se aprobaron el SRS y el SDD.
2. Se agregó el código mínimo del modelo de tareas.
3. Se etiquetó con `git tag -a v1.0 -m "Baseline v1.0: SRS+SDD approved + minimal build"`.
4. Se publicó como Release v1.0 en GitHub.
